PhraseSpeak is a simple web-based communication tool designed to help people who are unable to speak or have speech difficulties communicate more easily.

Features
Text-to-Speech: Converts typed messages into spoken words.
Frequently Used Phrases: Remembers phrases that are used 3 or more times.
Quick Phrase Buttons: Frequently used phrases can be clicked to speak them instantly.
Simple Interface: Uses a clean and accessible design with clear buttons and readable text.
Responsive Design: Works on computers, tablets, and phones.
Local Storage: Frequently used phrases are stored locally in the user's browser.
No Special Equipment: Only a device with a web browser is required.
Technologies Used
HTML – Creates the structure of the website.
CSS – Controls the appearance, layout, colours, fonts, and responsiveness.
JavaScript – Handles text-to-speech, phrase tracking, buttons, and local storage.
Web Speech API – Allows typed text to be converted into speech.
Browser Local Storage – Saves frequently used phrases on the user's device.
How to Use
Open index.html in a modern web browser.
Type a message into the text box.
Use the speech button to have the message spoken aloud.
Continue using common phrases.
After a phrase has been used 3 or more times, it can appear as a frequently used phrase.
Click a frequently used phrase to have it spoken quickly.
Requirements
A computer, tablet, or smartphone
A modern web browser
JavaScript enabled
A browser that supports text-to-speech

No installation or specialised hardware is required.

Project Purpose

The purpose of PhraseSpeak is to provide a free and simple digital communication option for people who may have difficulty speaking. The project focuses on accessibility, ease of use, and quick communication.

The file name is index.html

The project uses internal CSS and JavaScript within index.html, so the website can be run as a standalone file.
